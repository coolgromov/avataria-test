# avataria-test

![Аватария](https://mmo13.ru/download/games/3/2188.jpg)

**Аватария** — популярная социальная игра-симулятор жизни от компании *Tortugasocial*, доступная во ВКонтакте, Одноклассниках и Mail.Ru Играх. Игроки создают персонажа, обустраивают дом, общаются, работают, заводят питомцев и исследуют множество локаций.

Этот репозиторий содержит набор инструментов для работы с игровым протоколом Аватарии: **прокси-сервер** и **пример игрового бота**.
**Мой телеграм:** `@endmyprincess`

---

## 📦 Что внутри

| Файл | Описание |
|------|----------|
| `client.py` | Клиентская часть прокси. Принимает подключения от игрового клиента, обрабатывает входящие пакеты и перенаправляет их на реальный игровой сервер. |
| `server.py` | Серверная часть прокси. Подключается к официальному серверу Аватарии, обрабатывает ответы и модифицирует игровые данные (авто-уборка, подписки, VIP-статус, кастомные команды в чате и т.д.). |
| `protocol.py` | Реализация игрового протокола: кодирование/декодирование пакетов, работа с AMF-подобными структурами, шифрование, подсчёт контрольных сумм. |
| `bot.py` | Пример игрового бота, подключающегося к серверу Аватарии напрямую, с возможностью загрузки пользовательских модулей. |

---

## ⚙️ Возможности прокси

- Прозрачная передача трафика между клиентом и официальным сервером
- Модификация входящих/исходящих пакетов на лету
- Автоматическая уборка мусора в доме
- Выдача VIP-статуса, скинов, стикерпаков и эмоций
- Блокировка нежелательных действий (отношения, покупки и т.д.)

---

## 🤖 Возможности бота

- Авторизация через токен социальной сети
- Подключение к любому игровому серверу (ВК, ОК, Mail.Ru)
- Поддержка пользовательских модулей через аргумент командной строки
- Работа с игровыми событиями: вход в комнату, сообщения, авторизация

## 🚀 Запуск

### Прокси

Прокси слушает входящие подключения от игрового клиента и перенаправляет их на официальный сервер в зависимости от выбранной соцсети (`snid`).

### Бот

```bash
python bot.py <module_name>
```

Где `<module_name>` — имя Python-модуля с классом `Module`, реализующим логику бота.
